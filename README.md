## 规格口径

| 模块 | 长（沿台长） | 深 | 高 | 说明 |
|---|---|---|---|---|
| 水柜 | **720** | **1440** | 800 | 台面 750×1500 含镶边 30，柜体 720×1440 |
| 双柜 | **840 / 1000** | 720 | 570 | 双门，840 为默认 |
| 单柜 | **420 / 500** | 720 | 570 | 单门，420 为默认 |
| 空位 | **500–800** | 720 | — | 余量均分（10mm 步长） |

**镶边**：台面四边都镶，每条 30，柜体区 = 台长 − 60

**长度链**：`台长 = 30 + 水柜 720 + Σ柜宽 + Σ空位 + 30`

**深度链**：中央台 1500 − 30×2 = 1440（单侧 720）；边台 750 − 30 = 720（靠墙侧不镶）

**高度链**：800 = 台面 25 + 垫条 15 + 横梁 30 + 柜体 570 + 底净空 160

## 算法

1. **柜体区** `bodyL = 台长 − 60`
2. **可用排柜长度** `A = bodyL − 水柜 × 720`
3. **空位数** `n = ROUND(A × 30% ÷ 500)` ← 基数是可用排柜长度，不是台长
4. **柜体组合** `a×1000 + b×840 + c×500 + d×420`，剩余长度均分为 n 个空位（500–800）
5. **约束**：空位必须夹在两个柜体之间 → `n ≤ 柜体数 − 1`（柜体不足时可用水柜端头缝）
6. **排序**：空位不贴水柜 → 柜体空位交替 → 规格种类少 → 双柜多

## 布局规则

```
水柜 │ 双柜 │ 空位 │ 双柜 │ 空位 │ 单柜 │ 空位 │ 单柜
       └─ 双柜在前 ─┘    └── 单柜在后 ──┘
```

1. **先双柜后单柜**：水柜 → 双柜（宽者在前）→ 单柜（宽者在前）
2. **空位夹在两个柜体之间**，柜体与空位交替排列，不并柜
3. 只有单个柜体时，空位才落到水柜与柜体之间（2000 系列）
4. 同一尺寸给出最多 4 套方案，顶部 chip 切换

## 钢架布置

```
        ┌── 30×60 纵梁（上下各一道，前后共 4 道）──┐
   端 ══╪═════════╪═════════╪═════════╪═════════╪══ 端
        │30×60立柱│         │         │         │
        └── 20×40 托梁（柜底，空位不配）─────────┘
```

| 层 | 构件 | 规格 | 位置 |
|---|---|---|---|
| ① | C 型架 | 30×60 立柱 + 上下横梁 | 每个模块交界处，前后各一根立柱 |
| ② | 纵梁 | 30×60 · 模块宽 − 60 | 相邻两架之间，上下 × 前后 = 4 道 |
| ③ | 托梁 | 20×40 · 柜宽 | 每个柜底前后各一，空位不配 |
| ④ | 封板 | 冷板 · 柜体深 × 730 | 两端端封板 + 中央台中封板 |
| ⑤ | 可调脚 | M12 · 60 高 | 每榀架 2 只 |

## 常见问题

**Q：为什么某些尺寸提示「无法拆单」？**

柜体只能由 1000 / 840 / 500 / 420 组合，空位限定 500–800，因此可行长度是离散的。提示框会给出最近可行的台面长度，一键套用。

**Q：清单里的「×2」是什么意思？**

双面对称布置时，同一规格柜体在两侧各有一套，数量 = 单侧 × 2。水柜贯通整个深度，不翻倍；空位是布局位，也不翻倍。

**Q：数据会上传吗？**

不会。所有计算在浏览器本地完成，无网络请求。

**Q：可以改规格吗？**

可以，编辑 `app/index.html` 顶部的 `TYPES` / `CABS` / `SPEC` 常量即可。
